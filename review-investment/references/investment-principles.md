# 我的投资原则

## 使用说明

每条原则尽量写成可以验证的规则，并明确适用范围。没有明确规定的阈值或约束一律视为“未设定”，不得虚构。

## 技术面原则

### P1：均线排列原则

- 适用范围：使用日K线审核的上市股票。
- 类型：必要条件；其中明确写为“最好”的项目按偏好项处理。
- 数据口径：前复权日线收盘价；计算 `MA5`、`MA10`、`MA20`、`MA60`。至少获取足以计算最近连续120个交易日全部均线的历史数据。
- 数据时效：截至审核日最近一个已收盘交易日；不得用盘中价格代替收盘价完成最终判定。

#### 状态定义

1. **多头排列**：短期均线在上、长期均线在下，即
   `MA5 > MA10 > MA20 > MA60`，且均线整体向上。
2. **空头排列**：`MA5 < MA10 < MA20 < MA60`，且均线整体向下。
3. **均线密集度**：

   \[
   D_t=\frac{\max(MA5_t,MA10_t,MA20_t,MA60_t)-\min(MA5_t,MA10_t,MA20_t,MA60_t)}
   {Close_t}\times 100\%
   \]

4. **均线密集**：最近连续3个交易日均满足 `D_t ≤ 3%`。
5. **均线发散**：不满足“均线密集”，且均线间距呈扩大趋势。若既不密集、间距也未明确扩大，则标记为“过渡/纠缠状态”，不得强行归类为发散。
6. **均线均价**：`(MA5 + MA10 + MA20 + MA60) / 4`。
7. **均线斜率**：统一使用最近10个交易日的日均变化率。对任一均线 `MA`：

   \[
   S_{10}(MA)=\frac{MA_t/MA_{t-10}-1}{10}\times100\%
   \]

   `S₁₀(MA)` 表示该均线最近10个交易日的日均变化率。它只用于均线方向，不替代P2判断股价主方向的30日线性回归，也不替代10日短期加速度回归。

8. **整体向上/向下**：
   - 整体向上：`S₁₀(MA5)`、`S₁₀(MA10)`、`S₁₀(MA20)`、`S₁₀(MA60)` 均大于0。
   - 整体向下：上述四个斜率均小于0。
   - 若斜率正负混合：标记为“方向分化”，不得仅凭均线大小关系断言整体方向。
   - 审核结果必须逐条披露四个 `S₁₀` 数值。

#### 审核规则

**A. 均线发散时**

- 必要条件：`MA20 > MA60`，且中长期均线方向不得呈明确空头状态。
- 偏好项：`MA5 > MA10`。
- 偏好项：最新收盘价最好高于 `MA10`。
- 若必要条件未通过：P1 判定为“不通过”。
- 若必要条件通过但任一偏好项未通过：P1 判定为“有条件通过”。
- 若必要条件和两个偏好项均通过：P1 判定为“通过”。

**B. 均线密集时**

- 必要条件：最新收盘价高于均线均价，即
  `Close > (MA5 + MA10 + MA20 + MA60) / 4`。
- 若收盘价等于或低于均线均价：P1 判定为“不通过”。
- 若收盘价高于均线均价：P1 判定为“通过”。

**C. 过渡/纠缠状态**

- 不直接套用发散或密集规则。
- P1 判定为“信息不足/有条件通过”，并说明尚未形成用户定义的明确技术状态。

- 例外条件：未设定。
- 证据优先级：东方财富的前复权日K收盘价及据此计算的均线；若工具直接返回均线，需核对复权方式和计算周期。

### P2：股价运行方向原则

- 适用范围：使用日K线审核买入机会的上市股票。
- 类型：买入必要条件；4点钟方向为硬性否决。2点钟方向是最高偏好。
- 数据口径：使用最近30个交易日的前复权日线收盘价，以30日线性回归判断股价的主方向；同时计算10日线性回归作为短期加速度辅助指标。钟点方向只按30日主回归分类，不凭单日涨跌或图表视觉角度判定。
- 数据时效：截至审核日最近一个已收盘交易日。

#### 计算定义

主方向计算令最近30个交易日为 `i = 0, 1, ..., 29`，收盘价为 `Close_i`。短期加速度计算另取最近10个交易日，并使用相同的对数回归方法。

1. **回归趋势**：对对数收盘价进行线性回归：

   \[
   \ln(Close_i)=a+b\,i+\varepsilon_i
   \]

2. **30日主方向归一化日趋势斜率**：

   \[
   G=(e^b-1)\times100\%
   \]

   记30日结果为 `G₃₀`。`G₃₀` 表示主回归趋势对应的日均涨跌幅，避免不同绝对股价之间不可比，并作为钟点方向的唯一主分类指标。

3. **首尾日均变化率（交叉检查）**：

   \[
   E_{30}=\frac{Close_{29}/Close_0-1}{29}\times100\%
   \]

   以 `G₃₀` 作为主分类指标，以 `E₃₀` 检查方向是否一致；若二者符号相反，标记为“主方向不稳定”，不得给出无保留的通过结论。

4. **30日趋势稳定性**：同时报告30日线性回归的 `R²₃₀`。暂以 `R²₃₀ ≥ 0.60` 认定主方向较稳定；`R²₃₀ < 0.60` 认定为震荡或方向不稳定，并按3点钟候选状态审核。该阈值为当前操作口径，可由用户以后调整。
5. **10日短期加速度**：对最近10个交易日使用同样方法计算 `G₁₀`、`E₁₀` 和 `R²₁₀`，只用于说明短期相对主方向是在加速、减速还是背离，不改变钟点主分类：
   - `G₁₀` 与 `G₃₀` 异号：标记为“短期与主方向背离”。
   - 两者同号时，若 `|G₁₀| > |G₃₀|`：标记为“短期加速”。
   - 两者同号时，若 `|G₁₀| < |G₃₀|`：标记为“短期减速”。
   - 两者相等：标记为“速度基本一致”。
   - `G₁₀` 与 `E₁₀` 异号或 `R²₁₀ < 0.60`：补充标记“短期方向不稳定”，但仍以30日结果决定钟点方向。

#### 钟点方向

- **1点钟——快速上升**：`G₃₀ > 0.50%/日`，且 `R²₃₀ ≥ 0.60`。
- **2点钟——稳步上升**：`0.15%/日 < G₃₀ ≤ 0.50%/日`，且 `R²₃₀ ≥ 0.60`。
- **3点钟——横盘/震荡**：`-0.15%/日 ≤ G₃₀ ≤ 0.15%/日`，或者 `R²₃₀ < 0.60`。
- **4点钟——缓慢下降**：`-0.50%/日 ≤ G₃₀ < -0.15%/日`，且 `R²₃₀ ≥ 0.60`。
- **5点钟——快速下降**：`G₃₀ < -0.50%/日`，且 `R²₃₀ ≥ 0.60`。

所有边界按以上包含关系处理，不得根据图形观感改变分类。

#### 1点钟买入窗口的定义

1. **进入日**：按30日主回归判断，当前连续1点钟区间的第一个交易日。该日满足1点钟条件，其前一个交易日不满足1点钟条件。
2. **连续区间**：从进入日起到当前交易日，每个交易日均满足 `G₃₀ > 0.50%/日` 且 `R²₃₀ ≥ 0.60`；若中途有一天不满足，下一次重新满足时视为新的进入日。
3. **交易日条件**：进入日计为第1个交易日；当前处于进入后的第1至第10个交易日时，该条件满足。
4. **进入后累计涨幅**：

   \[
   R_{entry}=\left(\frac{Close_t}{Close_{entry}}-1\right)\times100\%
   \]

   其中 `Close_entry` 为进入日收盘价，`Close_t` 为当前收盘价。
5. **涨幅条件**：`R_entry ≤ 15%` 时，该条件满足；等于15%仍符合。
6. **二选一规则**：交易日条件或涨幅条件满足任意一项，即可通过1点钟买入窗口审核。只有“超过10个交易日”且“`R_entry > 15%`”同时发生时才不通过。
7. 缺少进入日或相应收盘价，导致两项条件均无法判断时，判定为信息不足。

#### 审核规则

1. **1点钟方向**：满足以下任意一项即可买入：
   - 当前处于进入1点钟后的第1至第10个交易日；
   - 从进入日收盘价到当前收盘价的累计涨幅 `R_entry ≤ 15%`。
   
   只有两项都不满足，即当前已超过第10个交易日且 `R_entry > 15%` 时，P2才不通过。
2. **2点钟方向**：最喜欢、优先级最高；满足定义即通过。
3. **3点钟方向**：必须同时满足P1的“均线密集”定义；密集则通过，不密集则不通过。
4. **4点钟方向**：完全规避，触发硬性否决，P2直接判定为不通过。
5. **5点钟方向**：允许逆势候选，但最新收盘价必须已经站上 `MA10`：
   - `Close ≤ MA10`：不通过。
   - `Close > MA10` 但 `Close ≤ MA20`：有条件通过。
   - `Close > MA10` 且 `Close > MA20`：通过，属于更理想状态。
6. 若 `G₃₀` 与 `E₃₀` 方向相反，或缺少足够数据完成滚动30日主回归、`R²₃₀`、MA10/MA20或均线密集计算：判定为信息不足，不得视为通过。缺少10日辅助回归时，钟点方向仍可按完整的30日数据判定，但必须注明“短期加速度信息不足”。

- 例外条件：未设定。
- 证据优先级：东方财富前复权日K收盘价及由此计算的30日主回归指标、10日短期加速度指标、MA10、MA20和P1均线密集度。

## 资金面原则

资金面原则使用独立的 `F` 编号，避免与基本面原则编号冲突。

### F1：融资余额稳定原则

- 适用范围：具有融资余额数据的A股融资融券标的。
- 类型：买入必要条件；单日或连续3日大幅流出属于否决情形。
- 数据口径：使用东方财富的每日融资余额 `B_t`，不是把“融资净买入额”直接累加。观察窗口为当前交易日及此前20个交易日，共21个数据点、20个变化区间。
- 数据时效：截至审核日最近一个已披露融资融券数据的交易日；若融资数据比行情数据滞后，必须单独标明日期。

#### 前置指标：融资余额 / 自由流通市值占比

设最新融资余额为 `B_t`，同一日期的自由流通市值为 `FFMC_t`：

\[
LR=\frac{B_t}{FFMC_t}\times100\%
\]

- `LR > 10%`：高杠杆拥挤标的，使用基准严格阈值。
- `5% < LR ≤ 10%`：使用基准严格阈值。
- `LR ≤ 5%`：低杠杆标的，使用放宽阈值。
- 融资余额与自由流通市值应尽量使用同一交易日数据；若日期不同，使用不晚于融资数据日期且最接近的自由流通市值，并分别披露日期。
- 无法取得或核对自由流通市值时，F1判定为“信息不足”，不得自行选择阈值档位。

#### 计算定义

窗口严格定义为21个交易日 `[T-20,T]`，共20个日度变化区间。

1. **20日累计变化率**：

   \[
   C_{20}=\left(\frac{B_t}{B_{t-20}}-1\right)\times100\%
   \]

2. **20日趋势斜率**：令21个融资余额数据为 `i=0,1,\ldots,20`，对其对数值进行线性回归：

   \[
   \ln(B_i)=a+b\,i+\varepsilon_i
   \]

   \[
   G_B=(e^b-1)\times100\%
   \]

   `G_B` 表示融资余额回归趋势对应的日均变化率。本原则不设置 `R²` 门槛，避免把低波动横盘误判为不稳定。

3. **单日流出比例**：

   \[
   F_{1,t}=\frac{B_t-B_{t-1}}{B_{t-1}}\times100\%
   \]

4. **连续3日流出比例**：

   \[
   F_{3,t}=\frac{B_t-B_{t-3}}{B_{t-3}}\times100\%
   \]

5. **窗口最差流出**：
   - `F_{1,\min}`：在 `[T-20,T]` 窗口内，计算全部20个单日变化
     \[
     \frac{B_i-B_{i-1}}{B_{i-1}}
     \]
     并取最小值。
   - `F_{3,\min}`：在 `[T-20,T]` 窗口内，计算所有满足起止点均位于窗口内的连续3日滚动变化
     \[
     \frac{B_i-B_{i-3}}{B_{i-3}}
     \]
     并取最小值；共18个连续3日滚动窗口。

#### 审核阈值

**基准严格阈值（`LR > 5%`）**

1. **融资余额平稳或趋升**：
   - `C₂₀ ≥ -2%`；
   - `G_B ≥ -0.10%/日`。
2. **没有大幅流出**：
   - `F₁,min > -3%`；单日流出达到或超过3%即触发否决。
   - `F₃,min > -5%`；任意连续3日流出达到或超过5%即触发否决。

**低杠杆放宽阈值（`LR ≤ 5%`）**

1. **融资余额平稳或趋升**：
   - `C₂₀ ≥ -3%`；
   - `G_B ≥ -0.15%/日`。
2. **没有大幅流出**：
   - `F₁,min > -4%`；单日流出达到或超过4%即触发否决。
   - `F₃,min > -6%`；任意连续3日流出达到或超过6%即触发否决。

#### 审核规则

- 先计算 `LR` 并确定适用阈值档位，再执行以下判定。
- **通过**：平稳或趋升的两项条件均满足，且未触发任何大幅流出否决。
- **有条件通过**：未触发大幅流出否决，但 `C₂₀` 与 `G_B` 中仅一项未满足。
- **不通过**：触发任一大幅流出否决，或 `C₂₀` 与 `G_B` 两项均未满足。
- **信息不足**：标的不是融资融券标的、无法取得至少21个有效融资余额数据、无法计算 `LR`，或数据口径/日期无法核对。
- 证据优先级：东方财富逐日融资余额及自由流通市值；审核结果必须披露 `LR` 及所用档位、`C₂₀`、`G_B`、`F₁,min`、`F₃,min` 和对应日期区间。

#### 市场系统性去杠杆与人工复核例外

1. **全市场指标口径**：使用东方财富可取得的沪深两市融资融券余额合计（全市场两融余额）`M_t`，并确保相邻两个数据点均为已收盘交易日、统计口径一致。
2. **单日变化率**：

   \[
   D_{\mathrm{mkt},t}=\left(\frac{M_t}{M_{t-1}}-1\right)\times100\%
   \]

3. **系统性去杠杆判定**：当 `D_mkt,t < -2.5%`，即全市场两融余额单日降幅严格大于2.5%时，认定该交易日发生“大盘系统性去杠杆”；单日降幅恰好为2.5%不触发。
4. **触发人工复核**：若标的因F1任一否决条件被判为“不通过”，且相关异常日同时属于“大盘系统性去杠杆”日，必须增加人工复核项，不得由Agent自动套用例外改判。
5. **人工复核证据**：同步比较以下信息，并披露日期、幅度及相对表现：
   - 标的股价与成交量变化，重点检查下跌是否伴随异常放量；
   - 标的所属板块或行业指数走势；
   - 标的融资余额变化与全市场、板块同期表现的差异。
6. **复核目的**：区分“随市场或板块发生的被动跟随调整”与“个股资金独立出逃”。若证据不足、相互矛盾，或更支持个股独立出逃，维持“不通过”。
7. **上调边界**：仅当人工复核确认主要属于被动跟随调整时，才允许将F1从“不通过”上调为“有条件通过”；任何情况下均不得依据本例外直接上调为“通过”。
8. **适用边界**：本例外只修正F1结论，不得覆盖P1、P2或其他原则的硬性否决；凡使用本例外，整体审核结论最高只能为“有条件符合”，不得判定为“符合”。

后续资金面原则继续使用 `F2`、`F3` 编号，重点定义成交量、换手率、主力资金、北向或南向资金、股东增减持与资金持续性等规则。

## 总评规则

- 任一硬性否决项触发：不符合
- 必要条件存在未通过项：不符合
- 仅偏好项未通过，或关键事实待确认：有条件符合
- 所有硬性项和必要条件通过且证据充分：符合
- F1因“市场系统性去杠杆与人工复核例外”由“不通过”上调后，按“有条件通过”参与总评，且整体结论最高为“有条件符合”。
